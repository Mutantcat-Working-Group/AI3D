## 目标

一个本地网页工作台，让用户与原会话中的 Agent 看着同一个 3D 模型，通过编号、彩色区域标记和对话，准确沟通修改位置及要求。适配目标面向不同 harness，当前首先接入 OpenClaw。

**一套审阅界面，兼容不同建模来源：** OpenClaw 写程序生成的参数化模型，以及 OpenClaw 调 Tripo 等工具生成的人偶，都进入同一套展示和反馈流程。

## 已确认的方向

- 保留各 harness 原本的主 Agent，不要求用户转用查看器厂商的 AI；当前实例由 OpenClaw 主控。
- 原会话是唯一对话入口；审阅页只显示模型与标注，在用户自己的标准浏览器直接操作。可将两个窗口并排摆放，不要求同页嵌入；不再适配 harness 内置浏览器。
- 模型采用单一大视窗，只显示 Agent 指定的当前版本；用户已撤回自行切换历史版本的方案，避免版本与标记错配。
- Agent 负责在审阅开始前交付正确最新版本；用户标注期间不得切换模型或丢失未提交工作。版本同步错误由 Agent 跟进，不转嫁给用户。
- 用户可旋转、缩放模型，双击表面落点标签，左键拖动旋转无需切工具；彩色画笔默认只标可见表面，不穿透。0.3 新标签统一用 A/B/C/D 等大写字母，同轮删除不重排、不复用；旧数字标记保留，见需求 R04。
- 点击「反馈给 Agent」，让 OpenClaw 得到实际位置、区域和标注编号并确认收到；缺少修改说明时在原会话主动询问，文字沟通即可，不要求语音，也不凭标记自行猜测修改。
- 参数化源工程保留，不能为了统一展示而丢失可编辑参数。
- 本轮布局要求已在 0.3 实现：缩小顶部标题并压缩上下非必要占位，把可用空间优先留给模型预览；用户手感待实测，见 R27。
- 本轮下载要求已在 0.3 实现：用户直接下载当前正在预览的模型版本，不必再请 Agent 整理文件，也不误用后台新版本；标准 Chrome 原档下载校验通过，见 R28。

## 当前选型状态

**初版采用 Three.js + 轻量标注层 + 本地 Node 服务。** 3D-Annotator 保留为研究参考，不作为运行依赖。OCP 仅作后续 CAD 子链参考。初版 GLB／STL 使用同一审阅流程，原始媒体文件不被标注写回。

0.2 已移除 0.1 的复制聊天框，保留原会话作为唯一入口。历史 Control UI 侧栏开发与用户阶段验收保留在 侧栏验收（`SIDEBAR-ACCEPTANCE-20260909.md`），不再构成未来产品依赖或验收门槛。Portal 入口任务已取消，既有宿主补丁未在本次回滚。能准确标记位置，不等于已支持任意模型自动精准修形。
